# 🚀 **Dashboard Application (PyQt5)** 🎨  

## 🌟 **Overview**  
This project is a **smart dashboard application** developed using **PyQt5**. The dashboard integrates multiple **control features**, including:  
🚦 **Traffic Sign Detection**  
🗺️ **Navigation System**  
📻 **Radio Control**  
💡 **Light & Fan Control**  
This **graphical user interface (GUI)** ensures an intuitive and efficient user experience.  

---

## ✨ **Features**  
The dashboard includes the following functionalities:  

🔘 **Home Button** – Returns to the main interface.  
🚦 **Sign Detection** – Initiates **traffic sign recognition**.  
🔓 **Unlock Button** – Locks or unlocks specific features.  
📶 **Bluetooth Button** – Handles **Bluetooth connectivity**.  
🗺️ **Navigation System** – Opens an interactive **map for navigation**.  
📻 **Radio Button** – Plays various **radio stations**.  
💡 **Light ON/OFF** – Toggles car **lights**.  
🌬️ **Fan Control** – Adjusts **fan speed** (Increase/Decrease).  

---

## 🛠 **Technologies Used**  
🚀 **Python 3** – Core programming language  
🖥️ **PyQt5** – GUI development framework  
🎵 **QMediaPlayer** – Media playback support  
🖼️ **QPixmap** – Image handling  
⏳ **QTimer** – Real-time updates  
⚙️ **QProcess** – External command execution  
🌐 **Webbrowser** – Opens URLs in a browser  

---


## ▶️ **How to Run**  
1️⃣ Ensure all dependencies are installed.  
2️⃣ Place all necessary **icons** (e.g., `home.png`, `lock.png`, `fan.png`, etc.) in the **project directory**.  
3️⃣ Run the application using:  
```sh
python3 mainApp.py
```

---

## 🔍 **Functionality Breakdown**  

🔒 **Lock Button** – Toggles between **locked/unlocked** states with `lock.png` and `lock-open-alt.png`.  
🏠 **Home Button** – Returns to the **main interface**.  
📶 **Bluetooth** – Connects to **Bluetooth devices**.  
🗺️ **Navigation System** – Opens an **interactive map**.  
🚦 **Sign Detection** – Recognizes **traffic signs** using **OpenCV**.
📻 **Radio** – Plays a **selected radio station**.  
💡 **Light Control** – Toggles **car lights** interactively.  
🌬️ **Fan Control** – Adjusts **fan speed** using plus and minus buttons.
